# Nexus screenshot checklist

Capture these images from a disposable save at 1920×1080 or higher. Do not show API keys, usernames, absolute file paths, or unrelated mods.

1. **Hero image:** player and cyan Echo visible together beside the crop field.
2. **Teaching:** F7 recording message while the player performs the morning routine.
3. **Generalization:** Echo approaching a mature crop placed somewhere different from the teaching day.
4. **Independent action:** player standing still while Echo waters or harvests.
5. **Own inventory:** before/after sequence showing the player's backpack unchanged and the selected chest receiving produce.
6. **Weather adaptation:** rainy farm with Echo skipping dry-crop watering.
7. **Recovery:** log or overlay showing refill-before-watering or full-inventory-to-deposit replanning.
8. **Configuration:** sanitized `config.json` with no API key field.

Use the hero image as the Nexus tile. Put teaching, generalization, and independent action first in the gallery so the concept is understandable without reading the full description.
